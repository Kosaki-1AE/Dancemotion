# Usage Examples

## Query Transformer concept

```bash
./gbmc_translate Attention
```

Expected idea:

```text
Transformer.Attention -> GBMC.Port
```

## Query Street Dance concept

```bash
./gbmc_translate Groove
```

Expected idea:

```text
StreetDance.Groove -> GBMC.Resonance
```

## Query Unix concept

```bash
./gbmc_translate Pipe
```

Expected idea:

```text
Unix.Pipe -> GBMC.Port
```

## Show all mappings

```bash
./gbmc_translate --all
```
