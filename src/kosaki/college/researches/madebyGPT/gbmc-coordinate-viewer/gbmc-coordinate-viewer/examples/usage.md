# Usage

## Install

```bash
pip install -r requirements.txt
```

## Show position

```bash
python gbmc_coordinate.py Groove
python gbmc_coordinate.py Research
python gbmc_coordinate.py Job
```

## Draw 3D coordinate space

```bash
python gbmc_coordinate.py Dance --draw
python gbmc_coordinate.py Groove --draw --output groove_space.png
```

## Use custom data

```bash
python gbmc_coordinate.py Groove --data data/coordinates.json --draw
```
